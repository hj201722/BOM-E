# 프로젝트: 봄이

## 프로젝트 목표
리뷰 기반으로 **상품 요약**과 **이미지 생성**을 지원하는 웹사이트 구축.

## 프로젝트 기획 배경
온라인 쇼핑에서 긴 리뷰와 신뢰성 문제로 어려움을 겪는 소비자들에게 가독성 높은 요약 리뷰와 신뢰성 높은 데이터를 제공하고자 합니다.

---

## 주요 역할 및 담당 기능

### 1. **Firebase와 프론트엔드 연결**
- **Firebase Realtime Database**와 **Storage**를 이용해 리뷰와 이미지를 안전하게 저장하고 관리.
- Django 백엔드에서 Firebase 데이터를 불러와 프론트엔드로 전송.
- 사용자가 생성된 요약 리뷰와 이미지를 빠르게 볼 수 있도록 구현.

### 2. **백엔드 작업**
- **Django**를 기반으로 Firebase와 통신하며 프론트엔드와 데이터가 원활히 교환되도록 로직 설계.
- 프론트엔드에서 요청된 데이터를 수신하고, 이를 Firebase에 저장 후 필요 시 데이터를 가공해 사용자에게 반환.

### 3. **프론트엔드 개발**
- **Bootstrap**을 활용해 Django와 호환되는 프론트엔드를 구현.
- 사용자 인터페이스를 직관적이고 반응형으로 설계하여 다양한 디바이스에서 최적화된 경험 제공.

---

## 사용한 주요 기술 스택

- **언어**: JavaScript, Python
- **백엔드 및 데이터베이스**: Django, Firebase Realtime Database, Storage
- **연결 및 연산**: Firebase와의 통신을 Django로 관리, 프론트엔드와 데이터를 동기화하여 실시간으로 결과 제공.
- **프론트엔드**: Bootstrap을 활용하여 Django와의 호환성을 높이고, 반응형 UI 구성.

---

## 프로젝트를 통해 배운 점
- Django와 Firebase 연동을 통해 데이터 통신 및 저장 구조 설계 방법 학습.
- Firebase와의 연결 및 백엔드 로직을 구현하며 데이터를 효과적으로 전송하고 관리하는 법을 터득.
