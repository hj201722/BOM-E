# 🌸 프로젝트: 봄이 (Review-based Product Summary and Image Generation)

---

## 🎯 프로젝트 목표
> **리뷰 데이터를 요약**하고, 이를 **이미지로 시각화**하여 소비자들이 방대한 리뷰 데이터를 빠르게 이해하고, 신뢰성 있는 구매 결정을 내릴 수 있도록 돕는 웹사이트를 구축합니다.

---

## 💡 연구 배경
- **문제점**: 
  - 방대한 리뷰 데이터로 인해 상품의 품질을 신속하게 파악하기 어려움.
  - 가짜 리뷰로 인해 소비자 신뢰 저하.
- **해결책**:
  - AI 기술을 통해 리뷰를 요약하고 분석하며, 시각화된 콘텐츠로 정보를 제공.
  - 가짜 리뷰 탐지 기술을 활용해 신뢰도 높은 정보를 전달.

---

## ⚙️ 주요 기능 및 기술 구현

### 1️⃣ **리뷰 요약 및 분석**
- AI 기반 NLP 모델 활용:
  - **SentenceTransformer**로 문장 단위 분석.
  - **k-means 클러스터링**으로 주요 주제 분류.
  - **FastText 모델**을 통해 클러스터별 텍스트 분류 및 학습.

### 2️⃣ **가짜 리뷰 판별**
- **페이크 리뷰 필터링**:
  - 평점 비율, 리뷰 길이, 작성 날짜, 감정 점수 기반으로 판별.
  - 가중치를 부여해 탐지 정확도를 높임.
- **AI 허브 데이터셋**과 비교해 검증된 리뷰만 선별.

### 3️⃣ **이미지 생성**
- 텍스트 기반 **프롬프트 엔지니어링**:
  - 제품명, 감정 상태, 키워드, 주요 문장 등을 포함.
  - 생성형 AI 모델(DALL-E 등)을 사용해 리뷰를 시각화.

### 4️⃣ **웹사이트 설계 및 구현**
- **백엔드**:
  - Django 프레임워크와 **Firebase Realtime Database** 사용.
- **프론트엔드**:
  - **Bootstrap**으로 반응형 UI 설계.
  - 사용자 친화적이고 직관적인 검색 및 리뷰 결과 화면 제공.

## 🌟 기대 효과

### ✅ **소비자 정보 접근성 향상**
- 리뷰 데이터를 요약하여 소비자가 핵심 정보를 빠르게 이해 가능.
- 시각적 콘텐츠로 정보 전달력을 강화.

### ✅ **신뢰성 있는 구매 지원**
- 가짜 리뷰 탐지를 통해 소비자 신뢰를 증대.
- 정보 기반의 올바른 구매 결정을 지원.

### ✅ **사용자 경험 최적화**
- 직관적 인터페이스와 반응형 UI로 편리한 사용자 환경 제공.
- 플랫폼 재방문율 및 사용자 만족도 향상.

### ✅ **시장 조사 및 분석 도구로 활용**
- 리뷰 데이터를 분석하여 기업과 마케터에게 유용한 피드백 제공.
- 제품 개선과 마케팅 전략 수립에 활용 가능.

## 🖼️ UI/UX 설계
1. **메인 화면**:
