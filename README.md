# 프로젝트: 봄이 (Review-based Product Summary and Image Generation)

## 프로젝트 목표
리뷰 데이터를 기반으로 **상품 요약** 및 **이미지 생성** 기능을 제공하여 소비자들이 정보 과부하 없이 신뢰성 있는 구매 결정을 내릴 수 있도록 돕는 웹사이트 구축.

---

## 연구 배경
- 현대 소비자들은 방대한 리뷰 데이터로 인해 상품의 품질을 신속하게 파악하는 데 어려움을 겪음.
- 가짜 리뷰와 리뷰의 신뢰성 부족은 구매 결정을 더욱 어렵게 만듦.
- **봄이**는 AI 기술을 활용하여 리뷰를 요약하고, 리뷰 데이터를 바탕으로 이미지를 생성해 정보를 직관적으로 제공하는 것을 목표로 함.

---

## 주요 기능 및 기술 구현
### 1. **리뷰 요약 및 분석**
- **AI 기반 NLP 모델**을 사용해 방대한 리뷰 데이터에서 주요 정보를 추출하고 요약.
- 문장 단위로 리뷰 데이터를 분할 후, SentenceTransformer와 k-means 클러스터링을 활용하여 리뷰를 분석.
- 주요 주제별로 분류된 데이터를 FastText 모델로 학습 및 예측.

### 2. **가짜 리뷰 판별**
- 가짜 리뷰 탐지를 위해 AI 허브의 데이터셋과 비교, 신뢰도 높은 리뷰만 필터링.
- 리뷰 평점, 길이, 날짜 분포, 감정 점수 등을 기반으로 가중치를 부여하여 탐지 정확도 개선.

### 3. **이미지 생성**
- 텍스트 기반 프롬프트를 구성해 리뷰 데이터를 시각화.
- 제품명, 감정 상태, 주요 문장, 키워드 등의 정보를 포함하여 생성형 AI 모델에 전달.

### 4. **웹사이트 설계 및 구현**
- **Django**와 **Firebase**를 활용한 백엔드와 데이터베이스 통합.
- **Bootstrap**을 활용한 반응형 프론트엔드 설계.
- 사용자 친화적 UI를 통해 상품 검색 및 리뷰 결과를 제공.

---

## 시스템 구조
- **백엔드**: Python 기반 Django 프레임워크 사용.
- **데이터베이스**: Firebase Realtime Database와 Storage를 이용한 데이터 관리.
- **프론트엔드**: Bootstrap을 활용한 직관적이고 반응형 UI 설계.

---

## 기대 효과
1. **소비자 정보 접근성 향상**: 
   - 리뷰 요약 및 이미지 생성 기능을 통해 소비자가 방대한 데이터를 효율적으로 활용.
2. **신뢰성 있는 구매 지원**: 
   - 가짜 리뷰 탐지를 통해 신뢰성 높은 정보를 제공.
3. **사용자 경험 최적화**: 
   - 직관적인 인터페이스와 효율적인 데이터 제공으로 재방문율 증가.
4. **시장 조사 및 분석 도구로 활용**:
   - 리뷰 데이터를 분석해 기업 및 마케터에게 유용한 피드백 제공.

---

## 연구 성과 및 향후 과제
- AI와 NLP 기술을 활용한 리뷰 요약 및 이미지 생성 가능성을 입증.
- 사용자 경험 개선 및 데이터 신뢰성 향상을 위한 지속적인 모델 개선 및 UI 업그레이드 계획.
